# 🌴 Holiday Countdown Web Application (23 Nov 2026)

A modern, responsive, and feature-rich Holiday Countdown web application created for your holiday starting on **November 23, 2026**.

## ✨ Key Features

1. **Live High-Precision Countdown**:
   - Real-time animated counters for **Days**, **Hours**, **Minutes**, and **Seconds**.
   - **Progress Bar & Airplane**: Visualizes percentage of journey elapsed towards departure day.
   - **Sleeps & Workdays Counter**: Shows exactly how many nights of sleep and remaining working days (skipping weekends) until takeoff.
   - **Total Breakdown Strip**: Instant conversion to total weeks, hours, minutes, and seconds.

2. **Themes & Atmosphere**:
   - 🌴 **Tropical Paradise** (Default)
   - 🌅 **Golden Sunset**
   - ❄️ **Alpine Winter**
   - 🏛️ **Mediterranean Escape**
   - 🌆 **Cyber Twilight**
   - **Built-in Ambient Sound Synthesizer** (Web Audio API): Synthesizes calming ocean waves swelling and crashing without requiring external audio files.

3. **Interactive Trip Planning Toolkit**:
   - 🧳 **Packing Checklist**: Pre-populated with travel essentials (Passport, chargers, adaptors, sunglasses). Supports adding custom items, checking off with strikethroughs, and auto-calculating % packed.
   - 📅 **Pre-Trip Milestones**: Checkpoints at 60, 45, 30, 14, 7, and 1 day before departure to ensure zero-stress prep.
   - 💰 **Holiday Budget & Weekly Savings Calculator**: Computes exactly how much money you need to put away each week to hit your spending target before Nov 23, 2026.
   - ⏰ **Dual World Clocks & Notepad**: Compare home time with your destination time zone (Tokyo, Bali, Paris, London, Hawaii, New York, etc.) and auto-saving itinerary notes.

4. **Celebration & Sharing**:
   - 🎉 **Canvas Confetti & Audio Chime**: Interactive celebration fireworks when you hit departure day or click "Preview Arrival Confetti".
   - 📤 **One-Click Share**: Copy shareable countdown status to clipboard or share via native Web Share dialog.
   - 💾 **100% Offline & Local Storage**: All settings, packing checkmarks, custom tasks, budget numbers, and notes are automatically saved to your browser.

## 🚀 How to Run and View the App

### Option 1: Direct in Browser (macOS)
Double click `index.html` or run in terminal:
```bash
open /Users/katharineyau/.gemini/antigravity/scratch/holiday-countdown/index.html
```

### Option 2: Local Python Server
Run the local lightweight server:
```bash
cd /Users/katharineyau/.gemini/antigravity/scratch/holiday-countdown
python3 -m http.server 8080
```
Then open `http://localhost:8080` in your web browser.
